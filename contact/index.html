Reporting a problem with a tool

If a tool gives an error, produces a file that does not look right, or does not work on your device, please include:

  • The name of the tool, or its page address.
  • What you expected to happen and what happened instead.
  • Your device and browser, for example “Android phone, Chrome” or “Windows laptop, Edge”.
  • The type and rough size of the file, for example “MP4 video, 300 MB” or “scanned PDF, 12 pages”.

Please do not attach private files. Because MediaPilot never uploads your files, we cannot see what you were working on, so a description is usually enough. If a sample file would help, we will ask, and a harmless test file that shows the same problem is ideal.

Suggesting a tool or feature

Many of the tools on MediaPilot were added because someone asked for them. Tell us what you were trying to do, and we will look at whether it can be done privately in the browser.

Copyright concerns

MediaPilot does not host any files uploaded by users, because files never leave the user’s device. If you believe something published on this website itself infringes your rights, email us with the page address and details, and we will respond promptly.
