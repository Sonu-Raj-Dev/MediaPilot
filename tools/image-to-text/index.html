Frequently Asked Questions

What is OCR?

OCR stands for Optical Character Recognition. It is a technology that recognizes text within images and converts it into machine-readable text you can copy, search and edit.

Is my image uploaded to a server?

No. MediaPilot processes images entirely in your browser using Tesseract.js. Your files never leave your device. The only network request is downloading the language model on first use, which is then cached.

Which languages are supported?

The tool reads English and Hindi automatically in a single pass, including images that mix both — no setup needed. Support for more languages is on the roadmap.

What image formats are supported?

JPG, PNG, WebP, GIF, BMP and TIFF images are all supported. For best results, use a clear, well-lit image with high contrast between text and background.

How can I improve OCR accuracy?

Use a high-resolution image, make sure the text is in focus and well-lit, and select the correct language. Cropping the image to just the text area can also help.
